# 🧠 Quiz: Самопроверка по Модулю 17 (Карьера Data Analyst 2027)

---

### Вопрос 1
Как в резюме стандарта 2027 года правильно описывать свои проекты?
- [ ] «Писал код на Python, делал запросы в SQL, строил красивые графики».
- [x] Формат XYZ: «Увеличил выручку на X% / Сэкономил Y млн руб за счет Z (когортного анализа и выявления просадки чекаута с помощью SQL и Looker Studio)».
- [ ] Перечислить 50 названий библиотек Python.
*Объяснение*: Нанимающие менеджеры ищут кандидатов, умеющих приносить измеримую финансовую пользу бизнесу.

### Вопрос 2
Как вести себя на техническом лайвкодинг-собеседовании с использованием AI-ассистентов?
- [ ] Молча копировать все ответы нейросети в окно терминала.
- [x] Рассуждать вслух, четко формулировать ТЗ для AI, показывать глубокое понимание структуры данных и вслух проводить Code Review сгенерированного кода, указывая на краевые случаи.
- [ ] Отказаться от использования ИИ и писать код на листке бумаги.
*Объяснение*: Интервьюеры оценивают архитектурное мышление, постановку задач и способность находить скрытые ошибки.

### Вопрос 3
Что является главным признаком сильного GitHub-репозитория аналитика данных?
- [ ] 100 форкнутых чужих репозиториев без собственных коммитов.
- [x] Оформленный README с постановкой бизнес-задачи, скриншотами дашборда, выводами для C-Level и воспроизводимым кодом (кнопка 'Open in Colab' + чистые датасеты).
- [ ] Файл с 10 000 строк неструктурированного кода без комментариев.
*Объяснение*: Репозиторий должен читаться как готовый бизнес-кейс за 2 минуты просмотра рекрутером или тимлидом.

### Вопрос 4
На поведенческом собеседовании (Behavioral Interview) вам задают вопрос по модели STAR. Что означает эта аббревиатура?
- [ ] System, Test, Action, Release.
- [x] Situation (Ситуация), Task (Задача), Action (Ваши действия), Result (Измеримый результат для бизнеса).
- [ ] Statistics, Trends, Algorithms, Regression.
*Объяснение*: Фреймворк STAR структурирует рассказ о вашем опыте решения кризисных ситуаций в компании.

### Вопрос 5
Вам предложили оффер с зарплатой ниже рынка, мотивируя это "отсутствием коммерческого опыта в AI-аналитике". Какова эффективная стратегия переговоров?
- [ ] Обидеться и заблокировать контакт рекрутера.
- [x] Презентовать сквозные портфолио-проекты с решенными бизнес-кейсами (RFM-аудит, A/B-тестирование, Text-to-SQL агент) и аргументированно запросить пересмотр грейда через 3 месяца испытательного срока при выполнении KPI.
- [ ] Сразу согласиться на любые условия.
*Объяснение*: Демонстрация твердых навыков решения реальных кейсов и готовность к прозрачным KPI нивелируют формальные пробелы в трудовой книжке.
