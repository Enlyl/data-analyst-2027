# 🧠 Quiz: Самопроверка по Модулю 1 (Excel)

### Вопрос 1
В чем ключевое преимущество `XLOOKUP` перед `VLOOKUP`?
- [ ] XLOOKUP работает быстрее ровно в 10 раз
- [x] Искомый столбец может находиться левее возвращаемого, формула не ломается при добавлении столбцов
- [ ] XLOOKUP работает только с числами

### Вопрос 2
Что произойдет при копировании формулы `=A$1 + 10` вниз на 5 строк?
- [ ] Ссылка сместится на A6
- [x] Номер строки зафиксирован знаком $, ссылка останется на ячейку A1
- [ ] Выдаст ошибку #REF!

### Вопрос 3
Почему в профессиональных отчетах избегают 3D круговых диаграмм (Pie Charts)?
- [ ] Они занимают слишком много памяти на компьютере
- [x] Они искажают пропорции восприятия долей и перегружают внимание визуальным мусором
- [ ] Их не поддерживает Excel

---

### Вопрос 4
В чем преимущество функции XLOOKUP (ПРОСМОТРX) перед классическим VLOOKUP (ВПР)?
- [ ] XLOOKUP работает только с числами.
- [x] XLOOKUP может искать влево, не ломается при вставке/удалении промежуточных колонок и имеет встроенную обработку ошибок (if_not_found).
- [ ] VLOOKUP больше не поддерживается в Excel.
*Объяснение*: XLOOKUP устойчив к структурным изменениям таблицы и более интуитивен по аргументам.

---

### Вопрос 5
Почему при расчете среднего чека в сводной таблице опасно брать 'Среднее по столбцу Total'?
- [ ] Excel округляет средние до целых чисел.
- [x] Если в строках таблицы содержатся товарные позиции заказа (order items), а не уникальные чеки, расчет усреднит стоимость позиций, а не средний чек заказа.
- [ ] Сводные таблицы не умеют вычислять среднее.
*Объяснение*: Уровень детализации (гранулярность) таблицы определяет корректность агрегации.
